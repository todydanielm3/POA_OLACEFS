# 📚 Plataforma POA - OLACEFS

**POA_OLACEFS** é uma aplicação desenvolvida com **Streamlit** que permite o cadastro, visualização e gerenciamento dos Planos Operativos Anuais (POAs) no contexto da OLACEFS (Organização Latino-Americana e do Caribe de Entidades Fiscalizadoras Superiores).

## 🚀 Funcionalidades

- 🔐 **Login seguro**
- 📝 **Cadastro de novos POAs**
- 📂 **Visualização de POAs existentes**
- 🧾 Registro de informações gerais, alinhamento estratégico e orçamento
- 💾 Salvamento de dados em banco de dados local (SQLite)

## 📦 Tecnologias Utilizadas

- [Python 3.12+](https://www.python.org/)
- [Streamlit](https://streamlit.io/)
- [SQLAlchemy](https://www.sqlalchemy.org/) (ORM)
- [SQLite](https://www.sqlite.org/)
- [Pandas](https://pandas.pydata.org/)
